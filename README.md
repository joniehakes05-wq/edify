# EDIFY

**That all may be edified of all.**
Doctrine & Covenants 88:122

EDIFY is a gospel-study community designed to help people share what they are learning and grow together.

## Design
- Warm cream, sage green, and charcoal
- Minimal, welcoming layout
- Study-focused community

## Technology
- React
- Vite
- Supabase

## Development

Install dependencies:

npm install

Start the development server:

npm run dev

Build for production:

npm run build
